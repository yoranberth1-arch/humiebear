HUMMIE BEAR WEBSITE
===================

Bestanden:
- index.html  -> hoofdwebsite
- style.css   -> volledige styling
- script.js   -> mobiel menu + jaartal
- assets/logo.svg -> eenvoudig Hummie Bear-logo

PLAATSEN OP COMBELL
1. Gebruik je Combell-webhosting.
2. Open de publieke map "www".
3. Upload alle bestanden uit deze map, inclusief de map assets.
4. Zorg dat index.html in de www-map staat.
5. Bezoek daarna je domein.

CONTACT
Het formulier gebruikt mailto:info@hummiebear.com. Maak deze mailbox aan bij Combell of pas het e-mailadres aan in index.html.

OPMERKING
De teksten, voorbeeldnamen en illustraties zijn opgezet als professionele basis. Vervang later contactgegevens, foto's, prijzen, Instagram/Facebook-links en definitieve logo-bestanden met jullie echte gegevens.
